# Stage 6 – Validation ⏳

Turn the regions of the behaviour map (stage 5) into named behaviours that can be trusted.

**Input:** watershed regions and ethograms from stage 5, the videos.
**Output:** a list of behaviours with example clips, and a comparison with manual labels where they exist.

## Plan

- Cut example clips from the longest bouts of each region and name the behaviour by watching them.
- Compare with hand-annotated behaviour, if the research group has any for some videos.
- Compare experimental groups, e.g. the female's cycle state (estrus vs diestrus).
